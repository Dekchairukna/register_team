อัปเดตเทมเพลตเกียรติบัตรแบบสมาคมกีฬาเปตอง น้ำเงิน–ทอง

แก้ไฟล์แล้ว 4 จุดหลัก
1) templates/_certificate_sheet.html
   - เปลี่ยนโครงเกียรติบัตรใหม่ให้จัดวางเหมือนภาพตัวอย่าง
   - โลโก้ 3 รูปอยู่ด้านบนกลาง
   - ชื่อหน่วยงานบรรทัดใหญ่/บรรทัดรอง
   - ข้อความขอมอบเกียรติบัตร
   - ชื่อผู้รับตัวใหญ่กลางหน้า
   - ข้อความหลักสูตร/กิจกรรม/รายการแข่งขัน
   - วันที่ สถานที่ วันที่ออกเกียรติบัตร
   - ลายเซ็น ตราประทับ และ QR ตรวจสอบ

2) static/certificate.css
   - เปลี่ยน CSS ให้เป็นหน้ากระดาษ A4 แนวนอน
   - เพิ่มพื้นหลังน้ำเงิน–ทอง มุมโค้งและกรอบทองแบบภาพตัวอย่าง
   - จัดตำแหน่งโลโก้ ข้อความ ชื่อผู้รับ ลายเซ็น และตราประทับใหม่

3) templates/certificate_settings.html
   - เพิ่มช่องกรอกให้ครบตามภาพตัวอย่าง:
     cert_org_sub = ชื่อหน่วยงานบรรทัดรอง
     cert_activity_text = ข้อความหลักสูตร/กิจกรรม
     cert_period = ช่วงวันที่จัดกิจกรรม
     cert_issue_date = วันที่ออกเกียรติบัตร
     cert_signer_position_2 = ตำแหน่งผู้ลงนามบรรทัดที่ 2
   - ยังอัปโหลดโลโก้ 3 รูป พื้นหลัง ลายเซ็น และตราประทับได้เหมือนเดิม

4) app.py
   - เพิ่มคอลัมน์ใหม่ในตาราง tournaments อัตโนมัติเมื่อเปิดระบบ
   - เพิ่มการบันทึกช่องใหม่จากหน้าตั้งค่าเกียรติบัตร
   - เพิ่มข้อมูลช่องใหม่เข้า certificate preview, certificate รายบุคคล และพิมพ์เกียรติบัตรแบบชุด

วิธีใช้หลังแตก zip
1) เปิด Terminal ในโฟลเดอร์โปรเจกต์
2) เข้า venv แล้วติดตั้ง requirements
   source venv/bin/activate
   python -m pip install -r requirements.txt
3) เปิดระบบ
   python app.py
4) เข้าเมนูตั้งค่าเกียรติบัตรของงานแข่งขัน
5) เลือกธีม "ทรงสมาคมกีฬาเปตอง น้ำเงิน–ทอง"
6) กรอกคำและอัปโหลดโลโก้/ลายเซ็น/ตราประทับ
7) กดดูตัวอย่างเกียรติบัตร

หมายเหตุสำคัญ
- ไฟล์นี้ไม่ได้ฝังโลโก้/ตราประทับ/ลายเซ็นจริงจากภาพตัวอย่าง เพื่อป้องกันปัญหาสิทธิ์การใช้งาน
- ถ้ามีสิทธิ์ใช้โลโก้จริง ให้อัปโหลดในหน้า "ตั้งค่าเกียรติบัตร" ได้เลย
