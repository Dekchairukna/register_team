อัปเดตล่าสุด: เพิ่มโหมดอัปเดตรายชื่อแทนข้อมูลเดิม

ตำแหน่งใช้งาน:
1. เข้าระบบแอดมิน
2. เลือกงานแข่งขัน
3. กด Import รายชื่อรวมทุกอีเวนต์
4. อัปโหลดไฟล์ Excel เทมเพลตระบบ
5. ถ้าต้องการแทนข้อมูลเดิม ให้ติ๊ก “อัปเดตรายชื่อแทนข้อมูลเดิมในงานนี้”

พฤติกรรมระบบ:
- ระบบตรวจไฟล์ก่อนเสมอ
- ถ้าไฟล์มีปัญหา จะไม่ลบข้อมูลเดิม
- ถ้าไฟล์ถูกต้องและติ๊กโหมดแทนข้อมูลเดิม ระบบจะลบรายชื่อสมัครเดิมของงานนี้ทั้งหมด แล้วนำเข้ารายชื่อใหม่จากไฟล์ Excel
- เกียรติบัตรและรายชื่อสมาชิกที่ผูกกับรายชื่อสมัครเดิมจะถูกลบพร้อมกัน เพื่อไม่ให้ข้อมูลค้าง
