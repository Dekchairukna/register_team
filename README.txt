ระบบรับสมัครทีมและนักกีฬา
========================

วิธีรันบน Mac
1) แตกไฟล์ ZIP และเข้าโฟลเดอร์โปรเจกต์
2) สร้าง virtual environment
   python3 -m venv .venv
3) เปิดใช้งาน virtual environment
   source .venv/bin/activate
4) ติดตั้งแพ็กเกจ
   pip install -r requirements.txt
5) รันระบบ
   python3 app.py
6) เปิดเว็บ
   http://127.0.0.1:8000

ฟังก์ชันหลักที่เพิ่มแล้ว
- สมัครเดี่ยว 1 คน
- สมัครคู่เลือกได้ 2 หรือ 3 คน โดยเสนอ 3 คนก่อน
- สมัครทีมเลือกได้ 3 หรือ 4 คน โดยเสนอ 4 คนก่อน
- กรอกชื่อทีมและต้นสังกัด
- เลือกได้ว่าแต่ละอีเวนต์มีค่าสมัครหรือสมัครฟรี
- เลือกคิดค่าสมัครต่อคนหรือต่อทีม
- เลือกบังคับแนบสลิปได้
- เลือกจำกัดจำนวนผู้สมัครหรือไม่จำกัดได้
- เปิดรายชื่อสำรองเมื่อเต็ม และตั้งจำนวนสำรองสูงสุดได้
- Import อีเวนต์จาก Excel
- Import ทีมหรือนักกีฬาจาก Excel แยกแต่ละอีเวนต์
- Import รายชื่อรวมทุกอีเวนต์จาก Excel ไฟล์เดียว ระบบแยกอีเวนต์ให้อัตโนมัติ
- ดาวน์โหลดไฟล์ Excel ตัวอย่างจากหน้าเว็บ
- ไฟล์ตัวอย่างรายชื่อรวมมีชีต “รายการอีเวนต์” สำหรับดูรหัสอีเวนต์ และชีต “รายชื่อสมัครรวม” สำหรับกรอกทุกประเภทในไฟล์เดียว
- Export รายชื่อสมัครเป็น Excel
- หน้าตรวจสอบสถานะด้วยรหัส REG
- แอดมินอนุมัติรายชื่อก่อนออกเกียรติบัตรได้
- เปิดเกียรติบัตรรายบุคคลหรือแบบทีมจากหน้าสถานะสมัคร
- พิมพ์เกียรติบัตรหรือบันทึกเป็น PDF ผ่าน Browser
- QR Code และเลข CERT สำหรับตรวจสอบเกียรติบัตรย้อนหลัง

การใช้งาน Excel
- เข้าเมนูจัดการอีเวนต์
- ดาวน์โหลดไฟล์ตัวอย่างก่อนกรอกข้อมูล
- ใช้ไฟล์ .xlsx เท่านั้น
- ระบบจะแสดงผลว่ารายการใดนำเข้าสำเร็จ และแถวใดมีปัญหา

หมายเหตุ
- ฐานข้อมูลเดิมจะถูกปรับ schema อัตโนมัติเมื่อเปิดระบบ
- เกียรติบัตรเป็นหน้า A4 แนวนอน กดปุ่ม “พิมพ์ / บันทึกเป็น PDF” ได้ทันที

หน้าตาเวอร์ชัน Modern SaaS
- Sidebar ซ้ายแบบเรียบสำหรับหน้าแอดมิน
- พื้นหลังขาวและเทาอ่อน
- การ์ดสรุปสี gradient พาสเทล
- Topbar และเมนู responsive สำหรับมือถือและ iPad
- หน้าแรกสำหรับผู้สมัครแยกจากแดชบอร์ดแอดมิน

หากเคยเปิดเวอร์ชันก่อนหน้าใน Browser ให้กด Command + Shift + R หนึ่งครั้งเพื่อรีเฟรช CSS

ระบบเกียรติบัตรเวอร์ชันใหม่
- ตั้งค่าได้จาก งานแข่งขัน > ตั้งค่าเกียรติบัตร
- รองรับโลโก้ด้านบนสูงสุด 3 รูป (PNG/JPG/WEBP)
- รองรับพื้นหลังเกียรติบัตร รูปลายเซ็น และตราประทับ
- มีธีมน้ำเงิน–ทองและธีมทองคลาสสิก
- มีปุ่มดูตัวอย่างก่อนใช้งาน
- ปริ้นรายบุคคลได้จากหน้ารายชื่อสมาชิก
- ปริ้นเกียรติบัตรรายบุคคลทั้งอีเวนต์ได้จากหน้าผู้สมัครเฉพาะอีเวนต์ หรือหน้าจัดการอีเวนต์
- การปริ้นทั้งอีเวนต์จะใช้เฉพาะรายชื่อที่กดอนุมัติแล้ว และไม่รวม Waiting List

เกียรติบัตร HTML/SVG Premium
- เกียรติบัตรใช้ HTML/CSS และพื้นหลัง SVG ที่ไม่มีข้อความฝังในรูป
- ข้อความ ชื่อผู้รับ อีเวนต์ รางวัล หน่วยงาน ลายเซ็น ตราประทับ และ QR Code เปลี่ยนตามฐานข้อมูล
- ถ้าไม่อัปโหลดพื้นหลัง ระบบจะใช้ธีมน้ำเงิน–ทองหรูอัตโนมัติ
- ถ้าอัปโหลดพื้นหลังเอง ระบบจะใช้พื้นหลังของงานแทน โดยยังวางข้อความ โลโก้ ลายเซ็น และ QR Code ด้วย HTML
- แนะนำให้เปิด Print Background Graphics ตอนพิมพ์จาก Browser เพื่อให้สีริบบิ้นและลายทองติดไปกับ PDF

ฐานข้อมูล PostgreSQL
---------------------
- ระบบรองรับ PostgreSQL แล้ว โดยอ่านค่าจากตัวแปร DATABASE_URL
- หากไม่ได้ตั้ง DATABASE_URL ระบบจะ fallback ไปใช้ SQLite สำหรับทดสอบในเครื่อง
- มี endpoint ตรวจสอบสถานะที่ /health
- มีสคริปต์ migrate_sqlite_to_postgres.py สำหรับย้ายข้อมูลเดิมจาก tournament_events.db
- ดูขั้นตอนโดยละเอียดใน POSTGRESQL_SETUP.md
- สำหรับ deploy จริง ควรตั้ง UPLOAD_FOLDER ให้ชี้ไป persistent volume เพื่อเก็บสลิป โลโก้ และรูปเกียรติบัตร


ฟังก์ชันปรับขนาดตัวหนังสือ
----------------------------
แถบด้านบนของหน้าเว็บมีปุ่ม A−, A และ A+ สำหรับลด คืนค่าปกติ และเพิ่มขนาดตัวหนังสือ
ผู้ใช้งานสามารถกดปุ่มเพิ่มหรือลดซ้ำได้หลายระดับ ระบบจะจำค่าที่เลือกไว้ในเบราว์เซอร์เครื่องเดิมอัตโนมัติ

เพิ่มล่าสุด: ผู้สมัครทั่วไปสามารถ Import รายชื่อหลายทีมและหลายอีเวนต์ได้เอง
- เปิดจากปุ่ม “อัปโหลดรายชื่อหลายทีม” บนหน้าหลักของแต่ละงานแข่งขัน
- ดาวน์โหลด Excel ตัวอย่าง กรอกหลายรายการในไฟล์เดียว อัปโหลดเพื่อพรีวิว แล้วกดยืนยัน
- ผู้สมัครไม่ต้องล็อกอินแอดมิน
- ระบบออกเลข REG แยกแต่ละรายการ เพื่อใช้ติดตามสถานะภายหลัง

อัปเดต: จัดการผู้สมัครหลายรายการและหน้ารายชื่อสาธารณะ
----------------------------------------------------
- หน้าแอดมินรายชื่อผู้สมัครมี checkbox เลือกหลายทีม และปุ่มเลือกทั้งหมด
- ลบรายการที่เลือกหลายรายการพร้อมกันได้
- ปุ่มลบทั้งหมดจะลบตามขอบเขตที่กำลังดู: หากเลือกอีเวนต์อยู่จะลบเฉพาะอีเวนต์นั้น หากอยู่หน้ารวมจะลบทุกอีเวนต์ในงานแข่งขัน
- หน้าแรกของผู้สมัครมีปุ่ม "ดูรายชื่อผู้สมัคร"
- หน้าสาธารณะแยกดูตามอีเวนต์ได้ และแสดงเฉพาะชื่อทีม ต้นสังกัด รายชื่อนักกีฬา และสถานะ Waiting List
- หน้าสาธารณะไม่แสดงเบอร์โทร เลขบัตรประชาชน เอกสารแนบ หรือรหัสติดตาม REG
